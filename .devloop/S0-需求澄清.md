- 生成时间：2026-11-23 22:12:44
- 轮次：自包含 GUI 安装器：内嵌 ime+dat，双击傻瓜式一键安装+卸载，红线不动（不写 Preload/不设默认 IME）

## 需求原话

> 可以把安装文件打包成一个exe或msi,安装时傻瓜式安装无需人工命令安装吗

> 用户确认：自包含 GUI exe（推荐）——内嵌 ime+dat，双击一键安装+卸载；保留 /step1..4 给开发者验证；走完整 dev-loop 并发布新版 release。

## 验收标准

- **AC1**：CMake `win32-mingw` preset 能编译出 `install-rospinyin-gui.exe`，CI Windows job 构建成功，产物上传为 release 资产。
- **AC2**：exe 内嵌 `rospinyin.ime` + `rospinyin.dat` 两个 PE 资源；运行时释放到 `%TEMP%` 下的唯一子目录，安装后清理临时目录；字节与源资源一致（宿主测纯逻辑：资源释放/字节校验函数）。
- **AC3**：双击 exe 显示 GUI：安装 / 卸载两个按钮；安装时分步显示拷贝/注册/写入进度，失败弹具体错误码与下一步提示；重复安装先弹确认框。
- **AC4**：点安装等价于依次执行现有 step1..4（拷贝两文件 + ImmInstallIMEW + Layout Text + Layout Display Name），HKL 记录与 CLI 版同位置（`HKCU\SOFTWARE\RosPinyin\Install`）；不写 Preload、不设默认输入法。
- **AC5**：点卸载等价于现有 /u：删除自己的注册表键与两个 payload 文件，不动其他输入法布局；运行中文件删除失败时提示重启后清理。
- **AC6**：guest 实机取证：双击安装→截图 regs/HKL + 文件存在 + Alt+Shift 能切到「中文(简体) - RosPinyin」→ 记事本敲字（含中文标点）候选与上屏正常→双击卸载→截图确认键与文件已清理。
- **AC7**：宿主侧 ctest 双配置（ON/OFF）全绿；`check_m1.py` 红线门禁全绿（安装器注册表白名单不被突破）；`check_docs.py`/`seams.py` 全绿。

## 待定与假设

- 假设 GUI exe 命名为 `install-rospinyin-gui.exe`，与原 CLI `install-rospinyin.exe` 并存；若 owner 希望最终用户只看到一个入口，S1 会给出"只发 GUI、CLI 留源码"的替代方案。
- 假设版本号 bump 到 `alpha0.0.4`（用户已确认发版）。
- 假设资源段命名遵循项目现有 `rospinyin_res.rc` 的 windres 惯例；base64 入库方案仅在没有构建产物可用时作为后备，S1 定稿。
- 本地无 MinGW：GUI exe 的本机编译不可行，验收依赖 CI 构建 + guest 实机；宿主侧只测纯逻辑（资源字节校验、步骤编排、错误码映射）。
