## 测试结果

**红灯（实现前）**：
- `cmake --build build --target rospinyin-punctuation rospinyin-host-key` → host-key 编译失败
  `ImeSessionState has no member named 'dquote_open'/'squote_open'`（4 处）。
- `./build/tests/rospinyin-punctuation` → 12 条失败：`open brace U+007B -> [U+FF5B] expected []`、
  `backslash U+005C -> [U+FF3C] expected [U+3001]`、`dollar -> [] expected [U+FFE5]`、
  `backtick -> [] expected [U+00B7]` 等（旧机械全角表与收敛目标不符）。

**绿灯（实现后，全量）**：
- `cmake --build build -j4` + `ctest --test-dir build` → **20/20 passed**（含新增 punctuation 20 键
  逐条断言、host-key 引号交替块）。
- `cmake --build build-host-off -j4` + `ctest --test-dir build-host-off` → **20/20 passed**。
- `check_m1.py --root .` → **111/111**；`check_docs.py .` → **7/7**；
  `seams.py --root .` → scheme-policy 15/15、ui-exit 13/13、imm32-abi 16/16，全在 cap；
  `check_mkdat.py --mkdat build/tools/mkdat/mkdat --root .` → OK。
- 交叉构建 `cmake --preset win32-cross && cmake --build --preset win32-cross` → exit=0
  （BUILTIN_TABLE=OFF / TRACE=OFF）。产物 `rospinyin.ime` SHA-256
  `161289a9d76c03a0572945a9bec83a8b2713f420025b209431c9f155b04638ac`（955,897 B），
  安装器 `9bfaa95d…`（未变，245,224 B），dat `db0c7bcf…`（未变，1,080,224 B）；
  已部署 `m0/share/`，HTTP 8000 返回 200。
- 测试自查：初版绿灯时 host-key 1 条失败（「English state leaves parity unchanged」写死
  `dquote_open==true`，但此前 5 次按键已翻成 false），改为「前后不变」断言后全绿——测试自身错误，
  非实现缺陷，已修正。
