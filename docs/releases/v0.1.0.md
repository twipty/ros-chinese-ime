# RosPinyin v0.1.0「墨」— 正式版

首个正式发布线。相对 alpha0.0.4，输入法主体新增按码点平面分片渲染的 `[全]` 模式与可选词组库；安装与分发形态不变（GUI 只登记 ReactOS，Windows 真机只走 CLI）。

## 资产

| 文件 | 用途 |
|---|---|
| `install-rospinyin-gui.exe` | 首选：自包含 GUI 安装器，双击安装/卸载 |
| `install-rospinyin.exe` | 诊断 CLI：`/step1..4`、`/status`、`/u`、`/fontinstall <DROID.TTF>` |
| `rospinyin.ime` / `rospinyin.dat` | 输入法主体与 v2 单字码表，必须同源同版 |
| `rhash.exe` / `SHA256SUMS.txt` | 校验工具与本次 tag 的实际资产哈希 |

**不在 release 资产内**：文津三片字体、nightly Droid 字体包、CC-CEDICT 词组库。三者均独立分发，详见下文。

本机构建指纹（CI 会用自己的 `SHA256SUMS.txt` 覆盖，发布后以资产清单为准）：`rospinyin.ime` `b3b83f0a…6505`、`rospinyin.dat` `db0c7bcf…3eba`、`install-rospinyin.exe` `d5d9c811…bea6`、`install-rospinyin-gui.exe` `ff7e2c94…6338`。

## 本次变更

- **P0 收口**：GUI 安装器双击安装/卸载、平台白名单仅 `ReactOS`、错误码与进度提示、CLI 分步路径保留。
- **P1 `[全]` 模式**：候选窗与编码窗按码点平面切换文津 P0/P2/P3 三片字体，实机确认扩展区字形为真实笔画而非豆腐块。按 `Ctrl+Shift+G` 切换，仅当前会话有效。**必须三字体齐备才能正常显示，缺少任意一个的后果不可预知**；字体从[文津官方发布页](https://github.com/takushun-wu/WenJinMincho/releases/tag/v2.100)自行下载校验，不从本 release 获取。
- **P2 nightly 字体包**：为 0.4.17-dev 提供独立可选的 Droid 字体包制作/安装流程；原版字体 SHA-256 固定 `82a74d0e…c5cdaf`，不入库、不替换系统已有字体。`/status` 可见字体与注册状态，`/u` 只清理本包安装的副本。stable 0.4.16 无需处理。
- **P3 评估**：Windows GUI 白名单**不登记**（无 Windows 实机证据），CLI 例外继续保留；结论见 `docs/reviews/WINDOWS-GUI-COMPATIBILITY-ASSESSMENT.md`。
- **M4 可选词组库**：CC-CEDICT 固定快照生成独立 `rospinyin-lexicon.dat`（CC-BY-SA，单独分发），`nihao`→「你好」首选、`jisuanji`→「计算机」首选，整词提交覆盖全部音节；词库缺失时保持单字行为。宿主测试覆盖 2/2 验收词。

## 安装与升级

1. 用 `SHA256SUMS.txt` 核对下载资产；GUI 安装器只在 ReactOS 上放行。
2. 安装完成后**重启系统**，用 `Alt+Shift` 切到「中文(简体) - RosPinyin」。
3. `[全]` 模式与 nightly 中文字体依赖按上文自行装齐；词组库如需要，按 `tools/mklex/README.md` 构建后放到 `C:\ReactOS\system32\`。
4. 卸载用 GUI「卸载」按钮或 `install-rospinyin.exe /u`；系统自带字体不会被删除。

## 已知限制

- `[全]` 模式缺任一字体片时显示结果不可预知；GUI 安装器弹窗内的 `http://10.0.2.2:8000/...` 是 guest 测试地址。
- M4 词组验收样本为 2/2；500 句常用词语料的首命中率评估尚未开展，不宣称 ≥80%。M2 单字首选率基线 46.2% 不被本版替换。
- 发布资产未包含可选字体/词库；离线安装需提前准备。
- 杀毒/SmartScreen 误报按 `alpha0.0.4` 发布说明的哈希核验流程处理。
