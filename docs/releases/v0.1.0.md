# RosPinyin v0.1.0「墨」— 正式版

RosPinyin 是 ReactOS 平台的独立第三方中文输入法软件包。本文只说明下载、安装、使用与字体依赖。

## 下载与校验

| 文件 | 用途 |
|---|---|
| `install-rospinyin-gui.exe` | 首选：自包含 GUI 安装器，双击安装/卸载 |
| `install-rospinyin.exe` | 诊断 CLI：`/step1..4`、`/status`、`/u`、`/fontinstall <DROID.TTF>` |
| `rospinyin.ime` / `rospinyin.dat` | 输入法主体与 v2 单字码表，必须同源同版 |
| `rhash.exe` / `SHA256SUMS.txt` | 校验工具与本次 tag 的实际资产哈希 |

下载后先用 `SHA256SUMS.txt` 核对资产。GUI 安装器只在 ReactOS 上放行；Windows 真机请用 CLI `/step1..4`。

**本 release 不包含字体与词组库**：文津三片字体、nightly Droid 字体包、CC-CEDICT 词组库均按下方提示另行获取。

## 安装与升级

1. 运行 `install-rospinyin-gui.exe`，按提示安装；或在命令行按 `tools/install-rospinyin/README.md` 走 CLI 分步安装。
2. 安装完成后**重启系统**，用 `Alt+Shift` 切到「中文(简体) - RosPinyin」。
3. 需要词组输入时，按 `tools/mklex/README.md` 构建词库并放到 `C:\ReactOS\system32\`；不装词库时单字输入不受影响。
4. 卸载用 GUI「卸载」按钮或 `install-rospinyin.exe /u`。安装器只清理自己登记的内容，系统自带字体不会被删除。

## 字体依赖（重要）

`[全]` 模式按码点平面使用文津明朝三片字体（P0/P2/P3）。**必须三字体齐备才能正常显示，缺少任意一个的后果不可预知。**

- 字体不在本 release 资产内，请从[文津官方发布页](https://github.com/takushun-wu/WenJinMincho/releases/tag/v2.100)自行下载并校验后安装。
- ReactOS 0.4.17-dev nightly 缺少 `DroidSansFallback.ttf`，中文会显示为 `?`。可选 Droid 字体包的制作、安装与清理见 `tools/droid-font-pack/README.md`；原版字体 SHA-256 为 `82a74d0ef369ec7979172023cfff87f04f0a617a2871c39ef6aeb0f399c5cdaf`。stable 0.4.16 无需处理。
- 字体包不入库、不随安装器或 release 分发，也不替换系统已有字体。安装后用 `install-rospinyin.exe /status` 可查看字体与注册状态。
- `Ctrl+Shift+G` 切换 `[快]/[全]`，仅当前会话有效。

## 注意事项

- GUI 安装器弹窗中的 `http://10.0.2.2:8000/...` 是 guest 测试地址，不是公网下载地址。
- 杀毒软件或 SmartScreen 误报时，先按 `SHA256SUMS.txt` 核验哈希再放行。
- 可选字体与词库均不随 release 分发，离线安装请提前准备。
