# M2 ReactOS 记事本验收操作单

> 版本：v1（2026-11-16）
> 目标：在 ReactOS 0.4.16 guestOS 中验证 M2 单字拼音引擎的端到端行为
> 前置：M1 已完成（`ImmInstallIMEW` HKL=`e0210804`，Alt+Shift 可切换到
> `中文(简体) - RosPinyin`，托盘「中」字图标可见）。见 `m0/vm/NOVNC-GUIDE.md` v7。

## 0. 验收范围与判定口径

| 项 | 判定标准 |
|---|---|
| 数据加载 | `rospinyin.dat` 能被 IME 从 `C:\ReactOS\system32\` 读取；44,355 字 / 418 音节在表内，候选默认只呈现有字频的 9,898 字（未登录生僻字需 `set_show_rare(true)`，见 HANDOVER §11.8） |
| 组合串 | 输入 `zhongguo` 显示 8 个字母并在 `[zhong]` / `[guo]` 处有音节下划线 |
| 候选窗 | 显示 9 条编号候选；`-` / `,` 上一页，`=` / `.` 下一页，页码如 `1/15` |
| 选字上屏 | 空格选首选；`1`–`9` 选当前页对应候选；翻页后数字按当前页解释 |
| `v` 键 | `nv` → 女；`lv` → 律；`lve` → 略；`nve` → 虐 |
| 编辑键 | Backspace 回退组合串；Esc 取消组合串且不上屏 |
| 稳定性 | 连续 100 字输入无崩溃、无残窗、无组合串卡死 |

## 1. 前置：把 M2 产物放进 guestOS

宿主 HTTP 共享：`http://192.168.0.204:8000/`（以 `m0/share/` 为根目录，
先 `curl -I` 确认可达）。以下全部在 guestOS 命令行执行，系统目录是
**`C:\ReactOS\system32`**（不是 `C:\windows\system32`）：

```bat
cd \
wget http://192.168.0.204:8000/rospinyin.ime
wget http://192.168.0.204:8000/rospinyin.dat
copy /y rospinyin.ime C:\ReactOS\system32\
copy /y rospinyin.dat C:\ReactOS\system32\
```

> noVNC 自动化注意：`keyboard.type()` 会丢 Shift，URL 必须逐字符显式注入
> Shift（`:` = Shift+Semicolon，`/` = 独立 Slash）。见 NOVNC-GUIDE v6。

然后**重启 guestOS**，确保 IMM32 卸载旧 `.ime` 再加载新版本。重启后先确认
Alt+Shift 仍能切到 `中文(简体) - RosPinyin`，托盘「中」字图标仍在。

> **覆盖报 `err=32`（"另一个程序正在使用此文件"）时**：说明这个 `.ime` 正被设为默认输入语言而常驻映射。
> 控制面板把默认输入语言临时切到「英语(美国)」→ 再 `copy /y` → 切回 → 重启。
> 完整原因与判据见 HANDOVER §6.4.1，不要靠"再拷一次"或换管理员身份硬试。

## 2. 打开记事本并激活 IME

1. `开始 → 程序 → 附件 → 记事本`（或命令行 `notepad`）。
2. 在编辑区点一下，按 `Alt+Shift` 直到托盘显示红色「中」字。
3. 若没切换成功，再按一次 `Alt+Shift`；不要用 `Ctrl+Space`（实测不可靠）。

## 3. 用例

| # | 输入 | 期望 | 实测 | 结果 |
|---|---|---|---|---|
| 3.1 | `zhong` | 组合串 `zhong`；候选首项 `中`；页码存在 | 组合串 + 下划线 + 候选窗 9 条 + `1/11` 页码（截图 `shot-1213`） | ✅ |
| 3.2 | 继续 `guo` | 组合串 `zhongguo`；两段下划线；候选首项 `国` | 两段下划线（首段黑、次段灰），候选窗切到 `guo`，首项「国」 | ✅ |
| 3.3 | `空格` | 上屏 `国`，组合串/候选窗消失 | `WM_IME_CHAR 0x56FD`，两窗隐藏 | ✅ |
| 3.4 | `nv` + `空格` | 上屏 `女` | `NV [SPACE]` → `女` | ✅ |
| 3.5 | `lv` + `空格` | 上屏 `律` | `LV` → 候选 `1{律}` | ✅ |
| 3.6 | `lve` + `空格` | 上屏 `略` | 先打成 `LVE` 再 `[BACK] E`，`1{略}`（回退也顺带验了） | ✅ |

| 3.9 | `zhong` 后按 `=` | 翻到第 2 页，页码 `2/n` | `vk=0xBB`（`=`）后候选换成第 2 页；页码显示随页递增 | ✅ |
| 3.10 | 第 2 页按 `1` | 上屏第 10 个候选 | 多页后 `1{衷}`、`4{郭}`、`7{仕}` 命中跨页序号 | ✅ |
| 3.11 | `-` | 翻回第 1 页 | `-` 回翻后仍可 `1{…}` 命中首项 | ✅ |
| 3.12 | `hao` 后 `Backspace` ×2 | 组合串变 `ha`，候选随之刷新 | `HAO [BACK]×3 → HAO`、`RENZHI [BACK] ICHU 1{人}`，回退后候选即时重算 | ✅ |
| 3.13 | `hao` 后 `Esc` | 组合串清空，不上屏任何字 | `HAO [ESC]` 后直接接 `NV`，中间无 `WM_IME_CHAR` | ✅ |
| 3.14 | 连续输入 100 个字母（混合合法音节） | 无崩溃、无残留窗口、候选窗跟随插入符 | 连打《陋室铭》《山居秋暝》共 100+ 字，全程无崩溃、无残窗；入口层 433 次按下与窗口层逐条对齐 | ✅ |
| 3.15 | 切到 `EN` 再切回 `中` | 组合串状态清空，可重新输入 | 末尾 lone-`Shift` 后 `H`/`I`/`U`/`B` 直接以拉丁字符上屏，再按 `Shift` 回到中文可继续输入 | ✅ |

> 判定依据是 `vmshare/imhost.log` 中同一轮运行的键序与 `WM_IME_CHAR` 折叠还原
> （详见 `HANDOVER.md` §11.16），全程未注入任何按键。3.9–3.11 的"页码文本"未逐页截图，
> 结论来自跨页序号命中；若之后要对外发布验收纪要，建议补一张第 2 页的图。

## 5. 失败回退

- 若组合串不出现：检查 `ImeSelect(TRUE)` 是否触发（引擎在 `on_select(true)`
  前拒绝 `feed()`）；已加 contract 断言防回归。
- 若候选是方框：先区分两种情况——**整页全方框**才是 CJK 字体未挂载（安装
  `NotoSansSC-subset.ttf` 或改用 `Droid Sans Fallback`，见 `ui/README.md`）；
  **只有零星几个方框**是候选里混进了扩展区生僻字，属数据问题，已由
  `PinyinSession` 默认过滤无字频字解决（HANDOVER §11.8）。
- 若 `.ime` 加载失败：回退到 M1 产物（`m0/share/rospinyin.ime.noicon` 是
  无图标版，不要用于最终验收），先确认 M1 仍可用再定位 M2 回归。
